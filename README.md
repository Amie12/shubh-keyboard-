## Install (Android)

> These apps are installed from an APK file, not from the Play Store. Download only from this repo.

1. **Download the APK.** Open the file you want in this repo (or the **Releases** page) and tap **Download**.
2. **Allow installs from your browser or file manager.**
   When Android asks, tap **Settings** and turn on **Allow from this source**.
   (Path on most phones: *Settings > Apps > Special access > Install unknown apps*.)
3. **Open the downloaded APK** from your notification bar or the *Downloads* folder.
4. Tap **Install**.
5. If **Play Protect** shows a warning, tap **More details > Install anyway**. This appears for any app installed outside the Play Store.
6. Tap **Open**.

Afterwards you can turn "Install unknown apps" back off.

## Troubleshooting

| Problem | Fix |
|---|---|
| "App not installed" | Delete any older version first, then install again. Check you have free storage. |
| Install button is greyed out | Turn on **Allow from this source** for the app you downloaded with (Step 2). |
| Play Protect warning | Tap **More details > Install anyway**. |
| APK will not open | Re-download it. A partial download can be corrupted. |
